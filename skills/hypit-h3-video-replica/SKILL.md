# Hypit + H3 肖像视频复刻

这是可安装的制作教程和本地辅助工具。安装此 Skill 不会安装所有依赖、连接账号或授权费用。不要改变用户已选的服务；本流程依赖 H3，换模型属于另外的方案。

## 安装与准备

用户只要求安装时，读取[安装说明](references/installation.md)，核对实际系统、工具和安装目录。补依赖需要对应安装权限；已有插件源、配置和素材不覆盖。不为验证安装启动 GPU、上传肖像或提交任务。

本 Skill 的目录是包含 `SKILL.md` 的实际安装目录，不是下载仓库的父目录。所有脚本和参考都在这个目录内。用本地环境检查工具发现缺项：

```bash
node "<技能目录绝对路径>/scripts/doctor.mjs" --h3-plugin-root "<实际H3插件根目录>"
```

`doctor.mjs` 只检查本地版本和文件，不读凭证、不请求平台 API；退出码 1 表示有未就绪项。环境通过也不表示账号、库存、许可或生成已通过。

## 制作

开始制作前读取[完整教程](references/tutorial.md)。按[任务模板](assets/task.example.json)建立新的制作项目，以本次素材、台词、字幕要求和授权为准；历史样片的配件、结束语、GPU 和预算不继承。

- 用实际可调用的 Hypit Skill 理解参考，写清 Brief、Treatment 和 Progress。Hypit CLI 可选；没有工具时说明缺项，不臆造文件或命令结果。
- 首帧需用户提供或用可调用的多图编辑工具制作并验收。准备好首帧和两段文案后才进入资源创建。
- H3 从完整上游插件执行，固定本版核对的提交。先读它的 Skill；首次账号配置按它的逐步引导推进，密钥由用户在本机官方 CLI 隐藏输入。
- 先读当前价格计划、确认所在地和用途许可，再按本次费用授权执行。批准安装不是批准 GPU 费用；默认不改卡、不提价、不重装旧实例，也不加第三次任务。
- 单次 2–15 秒。约 30 秒用两段；第一段用批准首帧，第二段用已验收的第一段尾帧。这种连续画面不能锁定原片动作或声音身份。
- 记录每次 manifest 和实际 artifact 路径，验收后再交给下一步。已有 `prompt_id` 只恢复原任务；提交状态不明时不再次 `generate`。
- 完成、失败和中断后确认实例状态；除非有明确保留授权，否则停机。30 分钟兜底不是平台总账硬封顶；第二段前回读用量与剩余预算。

## 本地处理与交付

`scripts/local-handoff.mjs` 只操作本地文件：保护配置备份、定位任务输出、生成拼接列表、保存精简用量快照和计算增量。先看 `--help`，参数和适用条件见教程。它不替你取得费用授权，也不强制执行总预算上限。

字幕已经烧入像素时不能只关字幕轨。干净底片只适合小范围、变化小、无遮挡的画面；EQ 只减轻音色和响度接缝，不承诺同一声纹。先出不覆盖原片的预览，完整观看、试听后决定采用。

交付实际成片、参考与成果对比、使用过的素材路径、任务记录和费用。区分累计与本次新增用量、估算与结算、未核验与零费用。未接受的缺陷明确标为待审，不用“已安装”或“能解码”代替创作验收。

本版验证范围见[验证说明](references/verification.md)。不要将肖像、视频、密钥、实际任务配置或平台回执提交到本 Skill 的 Git 仓库。
