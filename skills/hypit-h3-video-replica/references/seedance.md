# Seedance 2.5：即梦生成与本地成片

两次历史案例分别使用网页视频编辑和即梦CLI，再做本地声音、字幕、选段与封面处理。30秒/720P是案例参数，不是对所有账号和模型模式的永久保证。CLI命令结构在本机public/cn版1.0.2检查过；新制作需读取实际安装版本与实时规格。

## 连接前先准备

需要可调用的即梦CLI或用户明确选择的网页入口、用户自己的账号与积分、获授权参考媒体和肖像、本地FFmpeg/FFprobe，以及可查看视频的宿主。CLI安装来源由使用者确认；本仓库不包含该CLI、上游Skill或内部创作资料。没有CLI时不猜安装包、模型名或私有接口。

只读发现命令：

```bash
dreamina-canvas --version
dreamina-canvas schema
dreamina-canvas auth status
dreamina-canvas model find "Seedance 2.5" --type video
```

版本/schema检查本地契约；账号状态和模型目录属于服务查询，不执行付费生成。模型返回多项时结合需求选择，不取第一项。将实时返回的可调用model值、mode与规格写入任务；不得把展示名直接当作canonical model。

## 参考与提交

先查当前画布及已有任务结果，确认实际引用资源类型。五视图横向拼图可以拆成独立角度；本次1983×793输入曾因宽高比失败，拆图后成功，但这不是所有模式的通用尺寸要求。视频参考是否保留声音需在上传和制作前明确；音轨旧信息可能被生成结果保留。

在当前schema支持的结构内准备节点、引用、prompt和参数，报价后按有效授权提交。没有授权时只保存可审阅方案；报价和登录不等于同意消费。实际命令、积分确认机制和上传权限遵循当前工具文档，不提供绕过确认的命令。

为每个输出保存原提交身份、节点/资源身份和本地结果；若CLI与画布状态不一致，核对两端和可下载文件后恢复原任务，不因节点暂时缺失就新生成。重试不得换身份造成重复消费；不要把某次显示时间误认成另一任务完成时间。

## 三条结果如何筛成一条

先固定A/B/C编号，逐条提取镜头与音频信息，再按[统一四层验收](workflow.md#四层素材验收)筛选。不按生成顺序或文件大小选优。新人物、新字幕、目标品牌和准确声音各自检查；剔除原作者残留、旧招牌和不可用转场。

烧录字幕不能关闭字幕轨移除；本次大黑框遮挡被否决，最终通过逐镜头近景裁切避开原字，代价是视野变窄。下一次优先准备无字画面并在后期单独加字幕。

按剪辑表组织有效片段，先查首尾构图是否重复，再检查目标时长。模型画面中的新文字不能证明旧口播已替换；旁白需要目标品牌/项目名时，应准备准确完整稿并选定统一声音来源。

成片技术与观看验收见[导出检查](workflow.md#实际导出检查)。保存每次版本和实际成本记录。两次成功案例不代表全片身份一致、精准动作迁移或批量稳定。
