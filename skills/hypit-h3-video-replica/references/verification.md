# 验证范围

版本 1.1.1，整理日期 2026-09-29。

基础教程 v1.1 已通过 33 项本地检查和 37 段 Bash 语法检查；使用既有视频实际测试了 EQ、干净底片覆盖、带特殊字符路径的拼接、规格统一和并排对比，并完整解码。原视频与肖像不在公开仓库中，因此这些历史媒体测试不作为下载者可直接复跑的测试数据。

GitHub 安装版新增标准 Skill 入口、自包含引用、无凭证任务模板和只读本地环境检查。辅助脚本与原版的行为不变，只调整版本标识。H3 固定提交的 43 个文件与原实测安装逐文件核对一致；没有复制上游代码或模型。

仓库的 `npm test` 使用无个人信息的临时文件，检查用量计算、无效输入拒绝、文件不覆盖、任务目录归属和插件基线核对。`npm run verify` 检查发布文件清单、相对链接、语法和明显的隐私/密钥模式，不运行安装或云端命令。
