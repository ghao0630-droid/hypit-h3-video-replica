# 验证范围

## 托管 MiniMax H3 API（2026-10-10）

本轮加入优云智算 HTTPS 视频任务路线：`scripts/hosted-h3.mjs`、中文说明，以及估算、Data URL、清单和恢复的本地测试。测试用模拟 `fetch` 和本机回环服务，没有请求 `cp.compshare.cn`，没有读取真实密钥或提交付费任务。

覆盖的行为：默认 768P 而不是 480P；1080P、2K、480P、4K 的官方积分表和 1100 积分 = ¥9.90 的人民币折算；时长按 API 的 4–30 秒校验，并警告 CLI 0.4.4 只接受 768P/1080P/2K 与 4–15 秒；首帧编码为 Data URL；幂等键和空的 `taskId` 在第一次网络请求前落盘；响应丢失后用同一键恢复；已有任务号时不再 POST；超出 `--max-points` 或未给 `--yes` 时不提交；调试输出去掉 Authorization 和 Data URL。2026-10-10 的 5 秒 480P 实扣 20 积分只作为对照写在估算结果里，不改官方单价。

参考图模式另测：最多 9 张 `--reference-image`，请求字段为 `image_url.url` 加 `role: reference_image`，并与 `--first-frame` 互斥；每张图的 SHA-256 写入清单，恢复时先核对哈希和 `--spoken-language`，不一致不会重用幂等键。这些测试只用模拟 fetch，没有请求真实接口。

整仓 `npm test` 37 项通过（环境检查 7、托管 H3 13、交接工具 17）。`npm run verify` 通过：发布包 25 个文件，40 个相对链接、57 段 Bash 和 1 段内嵌模块；隐私和明显密钥模式检查通过。该检查不调用云端。
